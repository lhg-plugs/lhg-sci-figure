# sci-fig-style：期刊级视觉规范

> 目标：把"好看"翻译成可执行的硬参数——字号几 pt、线宽几 pt、DPI 多少、导出什么格式。
> 核心纪律：**同一张图里只许出现一种字号、一种字体家族；参数写进脚本，不许手调。**

## 1. 何时使用

- 规范卡已定、开始写绘图脚本时 → 全程对照本 skill 落参数
- 返修时审稿人说"图太糊""字太小""线太细"时 → 按第 3-5 节逐项排查
- 用户问"这个期刊的字号/线宽到底要多少"时 → 查第 3 节速查表

## 2. 输入与输出

- **输入**：规范卡（sci-fig-plan 第 4 步产出）
- **输出**：绘图脚本头部的统一样式块（代码片段）+ 导出语句

## 3. 硬参数速查表

### 3.1 字号（全文统一，只许一个正文字号）

| 用途 | 推荐值 | 说明 |
|---|---|---|
| 轴标签/刻度/图例 | 7-9pt | 通栏图用 7pt，双栏图可用 8-9pt |
| 子图编号 (a)(b) | 比正文大 1-2pt，加粗 | 位置统一左上角 |
| 特殊标注（显著性星号） | 与正文同字号 | 不许为了塞下而缩小 |

铁律：图缩小到实际栏宽后，**最小的字在屏幕上仍可读**。拿不准就打印出来看。

### 3.2 线宽

| 用途 | 推荐值 |
|---|---|
| 数据主线 | 1.0-1.5pt |
| 坐标轴/刻度线 | 0.75-1.0pt |
| 网格线/辅助线 | 0.25-0.5pt，浅灰 |
| 误差棒端帽 | 与主线同宽 |

红线：**线宽 < 0.5pt 的数据线在印刷时会断**，审计脚本会拦截。

### 3.3 配色

- 离散数据（≤8 组）：用色盲友好离散色板（如 Okabe-Ito 系），**避免红绿直接搭配**
- 连续数据：用感知均匀的顺序色标（如 viridis 系），色标条必须标注数值范围
- 同一研究的所有图用同一套配色（跨图一致性）
- 黑白印刷场景：用线型（实线/虚线/点线）+ 标记区分，不依赖颜色

### 3.4 分辨率与导出

| 场景 | 要求 |
|---|---|
| 矢量主件 | PDF（首选）/ SVG / EPS，无限放大不糊 |
| 位图预览/投稿系统 | PNG，≥300 dpi，线图建议 600 dpi |
| 照片/显微图 | TIFF/JPG，≥300 dpi |

铁律：**永远同时产出矢量主件 + 高 DPI 位图**，只给位图等于埋雷。

### 3.5 字体与嵌入

- 英文期刊：Arial / Helvetica / Times（三选一，全图统一）
- 中文期刊：中文宋体/黑体 + 英文 Times（中英文字体分别声明）
- 导出 PDF 时嵌入字体（避免投稿系统缺字体导致乱码/替换）
- 字体文件用系统自带或开源许可字体，不许用无明确许可的商用字体

### 3.6 色彩模式

- 在线发表：RGB
- 印刷：CMYK（转模式后**必须重新检查颜色**，鲜艳色会变灰）
- 导出时在脚本里显式声明色彩模式，不许"默认是什么就是什么"

## 4. 样式代码块模板（绘图脚本头部照抄）

```python
# 规范卡 fig01（目标期刊：____，版本 v1.0）
# 栏宽 89mm / DPI 600 / 字体 Arial 7pt / 线宽 1.0pt / RGB
import matplotlib
matplotlib.rcParams["font.family"] = "sans-serif"
matplotlib.rcParams["font.sans-serif"] = ["Arial", "Helvetica", "DejaVu Sans"]
matplotlib.rcParams["font.size"] = 7          # 全图统一字号
matplotlib.rcParams["axes.linewidth"] = 0.8  # 坐标轴线宽
matplotlib.rcParams["pdf.fonttype"] = 42      # PDF 嵌入 TrueType 字体
matplotlib.rcParams["ps.fonttype"] = 42

FIGSIZE = (3.5, 2.6)   # 英寸 = 89mm x 66mm
DPI = 600
# 导出：矢量主件 + 高清位图，缺一不可
# fig.savefig("fig01.pdf"); fig.savefig("fig01.png", dpi=DPI)
```

R / ggplot2 用户把对应参数翻译过去即可，参数值不变。

### 4.1 RGB 转 CMYK 的注意事项

- 转换时机：在线投稿用 RGB 交稿；只有确认走印刷流程才转 CMYK
- 转完必须**重新打开检查**：鲜艳的蓝色/绿色在 CMYK 下会明显变灰变暗，必要时微调配色
- 不要在同一个 PDF 里混用两种模式（部分页面 RGB、部分 CMYK）
- 截图/照片素材本身是 RGB，转 CMYK 后色彩偏移最大，提前跟用户预警

### 4.2 字体授权提醒

- Arial / Helvetica / Times New Roman 都是商用字体，随系统/Office 获得授权，自用投稿没问题
- 开源替代：DejaVu Sans、Liberation Sans（metric-compatible，可放心用）
- 中文字体注意授权：宋体/黑体随系统授权；网上下载的"免费字体"要看清许可范围（可否商用、可否嵌入 PDF）
- 拿不准时用开源字体交稿，授权风险为零

## 5. 多面板统一样式检查

- 所有子图：同一字号、同一线宽、同一配色、同一图例样式
- 子图编号格式统一：`(a)` `(b)` `(c)`，不许混用 `A.` / `a)` / `(A)`
- 共享坐标轴的子图：刻度范围对齐，不许各自为政
- 图例只放一次（多子图共享图例时放在整图下方或右侧）

## 6. 反模式

1. **字号随缘**：默认字号直接出图，缩到栏宽后刻度数字糊成一片。
2. **截图拼图**：用截图软件拼多面板，DPI 和字体全崩。
3. **RGB 直投印刷**：鲜艳的蓝绿色印出来发灰，返修重做。
4. **字体不嵌入**：编辑部打开是另一套字体，排版全乱。
5. **配色每次重选**：同一篇论文三张图三种配色，审稿人观感直接扣分。

质检门（样式阶段）：
- [ ] 脚本头部有统一样式块吗？参数与规范卡一致吗？
- [ ] 全图只有一种正文字号吗？
- [ ] 导出语句同时有矢量和位图吗？DPI 达标吗？
- [ ] 字体嵌入参数写了吗？
- [ ] 跑一遍 `figure_audit.py`，样式类规则全绿吗？

标准冒烟用例：按第 4 节模板生成样式块，审计脚本的 FIG-FNT-001 / FIG-LWD-001 / FIG-DPI-001 不应报警。
