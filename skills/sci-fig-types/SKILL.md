# sci-fig-types：图表选型手册

> 目标：给定研究问题，30 秒内定出图型；给定图型，知道它的画法要点和三条禁忌。
> 核心纪律：**数据决定图型**——先看数据长什么样，再选图，不许先定图型再套数据。

## 1. 何时使用

- sci-fig-plan 第 5 步需要展开图型细节时 → 查本手册
- 用户说"我想画 XX 图"但不确定合不合适时 → 按第 3 节核对
- 返修意见说"建议换一种呈现方式"时 → 按第 3 节找替代图型

## 2. 输入与输出

- **输入**：研究问题 + 数据形态（几组、连续/离散、样本量）
- **输出**：图型决策（首选 + 备选）与该图型的画法清单

## 3. 六大图型画法手册

### 3.1 折线图（趋势/时间序列）

画法要点：
- 横轴必须是连续量（时间/剂量/浓度），等距或按实际数值
- 多组用"颜色 + 线型 + 标记"三重区分，黑白印刷也分得清
- 误差带用半透明填充（alpha 0.2-0.3），不许用误差棒糊成刺猬
- 关键时间点/阈值用竖虚线标注并在图注说明

禁忌：
- 分类横轴上连折线（组别之间没有"趋势"）
- 超过 6 条线挤在一张图（拆面板）
- 纵轴不从 0 起却不标注截断（必须注明 broken axis）

### 3.2 柱状图/点图（组间比较）

画法要点：
- 优先用**点图 + 误差棒**代替纯柱状图（点图不夸大差异，更诚实）
- 误差棒必须说明是什么（标准误/标准差/95% CI），写进图注
- 显著性标注：`*` p<0.05，`**` p<0.01，并在图注写检验方法
- 柱子按效应大小排序（除非组别有天然顺序）

禁忌：
- 只画均值柱子不画误差（等于隐瞒变异）
- 纵轴截断夸大组间差异（截断必须明确标出）
- 3D 柱状图（任何情况下都不许，失真且过时）

### 3.3 箱线图/小提琴图（分布）

画法要点：
- 样本量 ≥10 才有资格画箱线图；小样本直接画散点叠加（ beeswarm / strip ）
- 箱线图叠加点（jitter），让读者看到真实数据分布
- 小提琴图必须说明核密度带宽，默认即可但要写进方法

禁忌：
- n=3 画箱线图（四分位数都是编的）
- 只给箱线不给样本量（n 必须标注）

### 3.4 散点图（相关/回归）

画法要点：
- 回归线 + 置信带一起画，光秃秃的散点等于没讲完故事
- 相关系数 r 和 p 值标注在图内空白处或图注
- 密集散点用透明度（alpha）或密度着色，避免"一坨黑"
- 双变量单位不同 → 标准化后再画，不许用双 Y 轴

禁忌：
- 双 Y 轴（本手册最高级别禁忌，见 sci-fig-plan 反模式）
- 用颜色编码第三个连续变量却不给色标条

### 3.5 热图（矩阵/多维）

画法要点：
- 行/列是否标准化必须说明（z-score / 行归一化 / 不处理）
- 色标条标注数值范围与单位，色标必须感知均匀、无跳变
- 聚类树要画就画全，不许只画一半
- 关键格子可叠加数值（数值过多时只标显著格）

禁忌：
- 红绿发散色标（色盲重灾区，用蓝-白-红或紫-绿系）
- 不说明标准化方式（读者无法复现）

### 3.6 多面板组合图

画法要点：
- 每个子图只讲一件事，子图之间用编号 (a)(b)(c) 串起叙事
- 共享图例只放一次；共享坐标轴的刻度对齐
- 面板布局与叙事顺序一致：左→右、上→下读完一个完整故事
- 整图共用一套样式（见 sci-fig-style 第 5 节）

禁忌：
- 子图编号跳号/乱序（审计脚本 FIG-SUB-001 拦截）
- 各子图字号线宽各自为政

## 4. 选型决策树（背下来）

```
要比较组间均值？ → 点图/柱状图 + 误差棒
要展示随时间/剂量变化？ → 折线图 + 误差带
要展示数据分布形态？ → n≥10 箱线图/小提琴，n<10 散点叠加
要展示两个变量关系？ → 散点图 + 回归线/置信带
要展示矩阵/多维模式？ → 热图（注明标准化）
一个故事讲不完？ → 多面板，每面板只讲一件事
```

### 4.1 误差棒选哪种（必知）

| 类型 | 含义 | 什么时候用 |
|---|---|---|
| 标准差 SD | 数据的离散程度 | 描述数据本身的变异 |
| 标准误 SE | 均值估计的精度 | 组间比较（最常用） |
| 95% 置信区间 CI | 均值 plausible 范围 | 正式统计推断场景 |

铁律三条：
1. 图注必须写清误差棒是哪一种（"误差棒为标准误"），不写等于没画
2. 同一张图里不许混用两种误差棒
3. SE 会随 n 增大而变小——大样本的 SE 棒很短是正常的，不许为了"好看"换成 SD

## 5. 反模式

1. **饼图依赖症**：类别一多就糊，堆叠柱或点图几乎总是更好。
2. **3D 特效**：3D 柱状图/饼图在学术出版里等于自曝不专业。
3. **默认配色直出**：软件默认配色是给探索性分析看的，不是给投稿的。
4. **显著性星号满天飞**：多重比较不校正就标星，方法学硬伤。

## 6. 自检与反馈

质检门（选型阶段）：
- [ ] 图型在第 4 节决策树里有对应分支吗？特例写理由了吗？
- [ ] 数据形态满足该图型的最低要求吗？（如箱线图 n≥10）
- [ ] 踩中第 3 节里该图型的禁忌了吗？
- [ ] 需要多面板吗？panel plan 写了吗？

标准冒烟用例："两组小鼠 5 个时间点血糖曲线"→ 决策应为折线图 + 误差带，而非柱状图。
