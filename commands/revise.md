# /lhg-sci-figure:revise —— 返修配图迭代

用户输入在 `$ARGUMENTS` 中：`<审稿意见或修改要求> [图表文件]`。

## 流程（加载 sci-fig-audit 全程指导）

### 1. 意见拆解
把审稿意见拆成逐条改图任务，每条标注：
- **类型**：数据问题（重算）/ 视觉问题（重画）/ 规范问题（重导出）/ 新增图（新建）
- **影响面**：只动本图，还是连带正文数字、其他子图一起动

### 2. 改前留档
原脚本复制为 `figures/figNN_plot.R1.py`（R1=第一轮返修），改后版本 `figNN_plot.R2.py`。**不许直接覆盖原稿**，返修信里要说清改了什么。

### 3. 逐条改
- 数据问题：先改数据处理，重跑，核对正文引用的数字是否同步更新。
- 视觉/规范问题：按规范卡改，改完跑审计脚本。
- 每条改完在任务清单打勾，附改前/改后对比说明（一句话）。

### 4. 复检与输出
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/figure_audit.py --target figures/ --format text
```
输出"返修对照表"：意见原文 → 改动说明 → 涉及文件 → 审计结果（blocker 必须 0）。

## 硬规则
- 返修改图覆盖原脚本不留档 → 不许。
- 改了图没核对正文引用的数字 → 不许。
- 审稿人意见只改一半就交付 → 不许（逐条打勾）。
